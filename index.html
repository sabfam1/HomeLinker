🏠 HomeLink

Two-way chat between school & home.
Needs a free Firebase database to sync across devices.

Firebase Setup

Free from Google. Takes ~2 minutes. console.firebase.google.com →

Go to Firebase Console → Add project (any name, disable Analytics)
In the left menu: Build → Realtime Database → Create database → choose any region → start in test mode
Go to Project Settings (gear icon) → scroll to "Your apps" → click </> Web → register app → copy the firebaseConfig object
Paste the config JSON below and click Connect
or fill manually

Config is saved in your browser. You only need to do this once per device.
